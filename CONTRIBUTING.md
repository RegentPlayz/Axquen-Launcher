# Contributing to Axquen Client Documentation

Thank you for helping improve the Axquen community and its documentation.

## Project boundaries

The GitHub repository is public, but the Axquen application is proprietary and
closed-source. The launcher source code is not open-source and is not accepted
through pull requests. Public access to documentation does not grant rights to
the application code, binaries, branding, or private assets.

## Accepted contributions

- Reproducible bug reports and compatibility reports.
- Feature suggestions and usability feedback.
- Documentation corrections and clarifications.
- Community assistance and FAQ improvements.
- Approved documentation and community-resource pull requests.

## Not accepted

Do not submit leaked or decompiled proprietary source code, unauthorized
third-party assets, malware, credentials, access tokens, private user data,
unlicensed content, or application binaries presented as official releases.

## Before opening a pull request

1. Check existing issues and documentation to avoid duplicates.
2. Keep changes focused and explain the user benefit.
3. Use clear headings and concise language.
4. Do not state unverified behavior as fact. Mark unknown details for developer
   confirmation.
5. Do not include personal information, secrets, or private logs.
6. Check relative links, Markdown rendering, and YAML syntax.
7. Preserve existing project content unless a maintainer approves a change.

## Reporting bugs

Use the GitHub **Bug report** issue form where available. Include Axquen build,
operating system, Minecraft version, loader, Java version, reproduction steps,
expected and actual behavior, and relevant sanitized logs.

## Suggesting features

Use the **Feature request** form. Explain the problem first, then describe the
proposed behavior and alternatives.

## Documentation pull requests

Documentation-only changes are preferred. The maintainer may request evidence,
screenshots, wording changes, or confirmation from the developer before
accepting claims about application behavior, privacy, compatibility, or
security.

## Review and licensing

Submitting a contribution does not transfer ownership of Axquen Client or grant
rights to proprietary software. By submitting content, you confirm that you
have the right to contribute it and that it does not violate third-party
rights. The project owner may accept, request changes to, or decline
contributions.
