# Support

## Where to get help

- Official support and community Discord: https://discord.gg/StdYxkEXRc
- Official website and download destination: https://client.axquenmc.online
- Public repository: https://github.com/RegentPlayz/Axquen-Launcher

## Before asking

1. Check [FAQ](FAQ.md) and [Troubleshooting](docs/TROUBLESHOOTING.md).
2. Confirm that Axquen was obtained from an official distribution channel.
3. Note the Axquen build, Windows version, Minecraft version, loader, and Java
   runtime.
4. Try to reproduce the issue with a minimal instance if practical.
5. Back up worlds and important instance data before changing mods or files.

## Useful report information

- Axquen version/build (if displayed).
- Operating system and architecture.
- Minecraft version and mod loader.
- Java version and memory allocation.
- Whether the issue occurs on a new or imported instance.
- Exact steps leading to the problem.
- Expected result and actual result.
- Relevant crash report or launcher log.

## Protect your information

Review logs before sharing them. Remove Microsoft account details, usernames if
you prefer, email addresses, access tokens, session files, IP addresses, file
paths containing personal information, and any other secrets. Never send your
password or authentication token to support.

Support response times and availability are not guaranteed.
