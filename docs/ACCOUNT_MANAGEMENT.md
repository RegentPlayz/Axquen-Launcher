# Account Management

Axquen lists Microsoft account support and an offline/local account mode where
supported.

## Microsoft accounts

Use the sign-in flow presented by Axquen. Complete authentication only through
the legitimate Microsoft flow. Do not share passwords, recovery codes, tokens,
or session files with community members or support staff.

The exact account storage and token-handling implementation has not been
verified in this documentation package. See [Privacy](PRIVACY.md) for items
requiring developer confirmation.

## Offline/local accounts

Offline/local identity mode may be available for environments that permit it.
It does not authenticate with Microsoft, prove ownership of Minecraft: Java
Edition, grant premium entitlements, or bypass server authentication. Servers
that require a valid authenticated account continue to enforce their own
requirements.

## Switching and profile management

Axquen lists account switching and account profile management. Use the
controls in the installed build and verify the selected account before
launching a game.

## Skins

The listed skin capabilities include custom skin upload, preview, and
application. Supported file formats, dimensions, account restrictions, and
sync behavior have not been confirmed here; follow the application's own
validation messages.

## Account safety

Never post account credentials, access tokens, session files, or unredacted
authentication logs in public issues or Discord channels.
