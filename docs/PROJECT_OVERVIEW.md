## Purpose

Axquen is an independent Minecraft Java Edition client and launcher intended
to bring common setup and gameplay tools into a cohesive application. Its
documented capabilities include instance management, mod discovery,
performance-oriented settings, account management, interface customization,
crash diagnostics, and in-game quality-of-life tools.

## Audience

The product is aimed at Minecraft Java Edition players, including PvP and SMP
players, modded Minecraft players, people maintaining multiple instances, and
players who value configurable interfaces and integrated mod discovery.

## Product objectives

1. Performance-oriented configuration.
2. Customization and usability.
3. Convenient instance management.
4. Easier mod discovery.
5. Better organization of Minecraft setups.
6. A polished launcher and in-game experience.

## Distribution

The primary distribution is a dedicated Windows executable launcher/installer
downloaded from the official website. Standalone JAR builds are also described
for compatible Minecraft Java instances and third-party Java launchers.
Android/tablet use is conditional on a compatible Java runtime and Minecraft
Java environment; a JAR is not a native Android application.
