# Mod Management

## Mod browser overview

Axquen includes an integrated mod discovery and installation interface with
source selectors for Modrinth and CurseForge.

## Finding mods

1. Open the Mods area in Axquen.
2. Choose the available source selector.
3. Search by mod name or relevant terms.
4. Review the mod description and listing details.
5. Use the available View action to inspect a listing.
6. Confirm that the mod supports the selected Minecraft version, loader, and
   environment before installation.

## Sorting and filters

The interface documents popularity sorting and filters for:

- Categories.
- Loaders: Fabric, Forge, NeoForge, and Quilt.
- Environment: Client and Server.
- Minecraft version.

The visible filters do not mean every mod supports every combination. Check
the mod's own compatibility information and dependencies.

## Installing mods

Use the Install action for a listing when the application makes it available
for the selected instance. Review any version or dependency choices shown by
the application. If the mod fails to load, consult its documentation and the
instance crash log.

## Updating and removing

The exact update and removal workflow depends on the Axquen build. Use the
instance content controls or the mod manager controls exposed by your version.
Back up important instances before removing or replacing mods.

## Troubleshooting compatibility

- Confirm Minecraft version and loader match the mod file.
- Check required dependencies and minimum versions.
- Avoid installing multiple mods that perform conflicting functions.
- Test a suspected mod in a duplicate or backup instance.
- Preserve the crash report and launcher log after removing sensitive data.
