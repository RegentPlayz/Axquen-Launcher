# Feature Catalogue

This catalogue describes the product capabilities supplied for Axquen Client.
Availability may vary by build and environment.

## Performance and FPS optimization

Axquen includes a performance-focused Game Mode, a built-in FPS Booster,
integrated Java configuration, configurable memory allocation, Java execution
configuration, and performance-focused game settings. The developer advertises
300+ FPS in certain high-graphics configurations and up to 1,000+ FPS in
lightweight or void environments. These are not guaranteed benchmarks.

Results depend on CPU, GPU, RAM, Java runtime, drivers, Minecraft version,
installed mods, render distance, graphics settings, and operating environment.
No particular frame rate is promised.

## Instance management

The instance library supports creating, launching, searching, sorting,
editing, duplicating, deleting, opening folders, managing installed content,
and viewing instance metadata. Separate instances help keep modpacks, versions,
and configurations isolated.

## Import from other launchers

The import interface lists Modrinth, CurseForge, Prism Launcher, MultiMC,
GDLauncher, ATLauncher, Dawn (Feather), Lunar Client, and TLauncher. Detection
depends on local paths, profile format, and compatibility. Successful import
is not guaranteed for every installation. Axquen is not affiliated with or
endorsed by these launcher projects.

## Mod browser

The integrated browser supports search, mod information views, installation,
popularity sorting, category filtering, loader filtering, environment filtering,
and Minecraft version filtering. Source selectors include Modrinth and
CurseForge. The visible loader filters include Fabric, Forge, NeoForge, and
Quilt. A mod's own version, dependency, environment, and loader requirements
still apply.

## Crash diagnostics and recovery

The client can detect startup crashes, surface diagnostic information, identify
potentially faulty mods or conflicts, and offer supported recovery options.
Where available, suspected mods may be disabled or removed. Not every crash can
be automatically diagnosed or repaired. Back up important instances first.

## Account management

Listed account capabilities include Microsoft account support, offline/local
account mode where supported, account switching, profile management, custom
skin upload, skin preview, and skin application. Offline mode does not
authenticate through Microsoft, provide ownership entitlements, or grant
premium server access.

## Themes and interface customization

Customization includes dynamic themes, custom accent colors, cyan, pink, amber,
and green theme options, additional color customization, interface animations,
a title-screen switcher, and a custom pause menu.

## Modular HUD

HUD controls listed for Axquen include movable and resizable components, ping
display, armor HUD, text colors, background opacity, corner radius, component
positioning, and individual component customization.

## Friend Protection System

The feature supports adding friends, premium and offline identities where
applicable, online/offline status display, and a “Can't Hit” setting intended
to reduce accidental friendly fire. Exact identity and server behavior may
depend on the environment.

## Distance Waypoints

Players can create custom waypoints, save useful locations, display waypoint
positions, and view distance information, including long-distance visibility.

## Controllable Zoom

The zoom feature is described as smooth and adjustable, with controllable zoom
level and movable controls where supported.

## Loot Beams

Loot beams provide visual indicators for dropped items to make them easier to
notice and identify.

## Item Overlays

Visual overlays are listed for supported weapons, tools, held items, and other
inventory items.

## Client presets

Axquen includes four pre-configured client presets intended to help users
configure the client quickly. Their names and exact settings have not been
provided and are intentionally not invented.
