# Installation

## Windows launcher

The Windows launcher is the primary Axquen distribution.

1. Open the official website: https://client.axquenmc.online
2. Locate the current Windows download on the official site.
3. Download the installer only from an official distribution channel.
4. Run the downloaded installer and follow its prompts.
5. Launch Axquen from the installed application entry.
6. Sign in using a supported account mode and select or create an instance.
7. Review Java and memory settings if a game launch requires adjustment.

The precise installer filename, minimum Windows version, installation
directory, and update procedure have not been supplied. Check the official
website and the installer itself. No direct installer URL is published here.

## Standalone JAR

Standalone JAR builds are intended for compatible Minecraft Java instances,
compatible third-party launchers, and compatible Android/tablet Java
environments.

General guidance:

1. Confirm that the JAR build matches the intended Minecraft and loader
   environment.
2. Back up the target instance before changing its mods.
3. Use the target launcher's normal instance folder or mods-folder workflow.
4. Place the JAR in the appropriate `mods` folder only where the build is
   intended to be used as a mod.
5. Start the instance and review logs if it fails.

The exact JAR filename, required dependencies, supported Minecraft versions,
loader matrix, and installation-specific steps require confirmation from the
release notes or developer. Do not assume that every JAR is a drop-in mod for
every loader.

## Android and tablet environments

A `.jar` is not an Android APK. Android use requires a compatible Java runtime
and a Minecraft Java environment capable of loading the relevant build.
Compatibility varies by device, runtime, launcher, and Minecraft version.
Universal Android compatibility is not claimed.

## Official distribution channels

Use the official website, official Discord announcements, official Google
Drive mirrors controlled by the developer, or the official GitHub repository.
The official website is the primary download destination. Avoid third-party
repackaged installers and unverified mirrors.

## Before updating

Back up important worlds and instance data. Confirm version and loader
compatibility for installed mods. Review official release notes before
replacing a working installation.
