# Axquen visual assets

This directory contains the official logo and product screenshots used by the
repository README.

## Expected files

| Path | Purpose |
|---|---|
| `axquen-logo.png` | Official monochrome angular AXQUEN symbol |
| `screenshots/home-dashboard.png` | Main launcher dashboard |
| `screenshots/instances-library.png` | Instance library |
| `screenshots/mod-browser.png` | Integrated mod browser |
| `screenshots/launcher-import.png` | Import-from-other-launchers dialog |

The files included in this package are the images supplied with the
documentation request. Replace them only with approved, current Axquen assets.
Do not substitute unrelated images or recreate the official logo.

For best results, use crisp PNG screenshots at their original aspect ratio.
Before publishing screenshots, check that they do not expose private account
details, personal file paths, tokens, or other sensitive information.
