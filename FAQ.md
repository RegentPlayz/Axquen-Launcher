# Frequently Asked Questions

## What is Axquen Client?

Axquen is an independent Minecraft Java Edition client and launcher developed
by Regent Playz. It combines instance management, mod discovery, account
options, customization, performance settings, and in-game quality-of-life
features.

## Is Axquen free?

Pricing and licensing terms for end users have not been confirmed in the
information supplied for this documentation. **Developer confirmation
required.** Check the official website for current terms.

## Is Axquen open-source?

No. The application is proprietary and closed-source. This public repository
contains documentation and community resources, not the launcher source code.

## Which Minecraft versions are supported?

The exact supported-version matrix is not confirmed here. Check the official
website or release announcements for the current build's compatibility.

## Does Axquen support Fabric, Forge, NeoForge, and Quilt?

These loader filters appear in the mod browser. Actual compatibility depends on
the Axquen build, Minecraft version, loader version, and each mod's
requirements. Do not assume every combination is supported.

## Can I import existing instances?

Axquen provides a launcher-import interface for several launchers. Successful
detection and import depend on local installation paths, profile format, and
compatibility. See [Instance Management](docs/INSTANCE_MANAGEMENT.md).

## Can I use Microsoft accounts?

Microsoft account support is listed as an Axquen capability. Follow the
authentication flow presented by the application and never share account
credentials with support.

## What is offline account mode?

It is a local/offline identity mode where supported. It does not provide
Microsoft authentication, prove Minecraft ownership, or grant premium server
access. Servers that require authenticated ownership still require a valid
eligible account.

## What is the standalone JAR?

It is a Java archive intended for compatible Minecraft Java instances and
third-party launchers. It is not a native Android application.

## Does Axquen work on Android?

Some compatible Android/tablet Java environments may be usable with standalone
JAR builds. This requires a compatible Java runtime and Minecraft Java
environment; universal Android support is not claimed.

## Can I install mods through Axquen?

The launcher includes an integrated mod browser with search, source selection,
sorting, and filters. Mod compatibility and installation availability depend
on the selected instance and mod metadata.

## How do I configure Java?

Use the Java configuration controls provided by the launcher where available.
The exact settings and runtime selection behavior depend on the current build.
See [Installation](docs/INSTALLATION.md).

## How does the FPS Booster work?

Axquen describes a built-in performance-focused Game Mode and FPS Booster.
Implementation details and reproducible benchmark methodology have not been
provided. Advertised FPS values are not guarantees.

## How can I report crashes?

Use the official Discord support destination and provide the Axquen build,
Minecraft version, loader, Java version, reproduction steps, and sanitized
crash logs. See [Support](SUPPORT.md).

## Where can I download Axquen?

Use the official website: https://client.axquenmc.online. Do not rely on
unofficial mirrors or invented direct download URLs.
